## Архитектура новых функций
- `packages/ltl_system/` — локальный Flutter-плагин (Android, Java), подключён в `pubspec.yaml` через `path:`.
  Регистрируется автоматически (GeneratedPluginRegistrant), `MainActivity` не меняется. Канал: `ru.ltl.system/methods`.
  - `LtlSystemPlugin.java` — диспетчер вызовов: тяжёлые операции в фоновом потоке, ответ в главном.
  - `DevTools.java` — ADB, отладка по Wi‑Fi, скорость анимаций, открытие параметров разработчика.
  - `DeviceTools.java` — сведения об устройстве, определение YaOS, IP-адрес, открытие ссылок.
  - `lib/ltl_system.dart` — Dart API: `LtlSystem`, `AdbStatus`, `LtlDeviceInfo`. Ошибки не роняют интерфейс, а возвращают значения по умолчанию.
  - Манифест плагина объявляет `WRITE_SECURE_SETTINGS` и `<queries>` для пакетов Яндекса; он сливается с манифестом приложения.
- `lib/ltl/ltl_strings.dart` — строки новых функций (ru + en) отдельно от gen-l10n, чтобы не перегенерировать 16 файлов локалей.
- Настройки новых функций хранятся в SharedPreferences, схема базы Drift не меняется.

### Этап 2 — раздел «Разработка» (2026-11-09)
- Добавлен плагин `ltl_system` (см. «Архитектура»).
- Новая страница `lib/widgets/settings/developer_settings_page.dart` и пункт «Разработка» в главном меню настроек:
  - карточка статуса ADB: включён/выключен, адрес в сети (IP:порт), режим разработчика, системное разрешение;
  - «Отладка по ADB» — переключатель со статусом;
  - «Отладка по Wi‑Fi» (Android 11+);
  - скорость системных анимаций: 1x → 0.5x → выкл. (интерфейс ТВ становится отзывчивее);
  - открыть параметры разработчика, обновить статус, сведения об устройстве (модель, Android, сборка, YaOS, IP);
  - статус обновляется сам при возврате в лаунчер.
- Android разрешает менять эти настройки только приложению с разрешением `WRITE_SECURE_SETTINGS`.
  Его выдают один раз с компьютера:
  `adb shell pm grant com.leanbitlab.ltvL android.permission.WRITE_SECURE_SETTINGS`
  (debug-сборка: `com.leanbitlab.ltvL.debug`). Без разрешения лаунчер показывает подсказку с этой командой.
- Переведён пункт «Support & Donate» в меню настроек.
- Коммиты: `2dc70a1`, `77a56b0`, `eb4c129`, `9c5f6da`, `ee4e404`, `c8b7ab9`, `df8b2e1`, `084009c`, `5b291f9`, `7b446df`.

## Как собрать и проверить
- Локально: `flutter pub get`, затем `flutter build apk --debug` или `--release` (Flutter 3.24.5, Java 21).
- GitHub Actions: workflow «Release APK» → Run workflow → ветка `feature/ltl-ru`, тег вида `v-dev-ru`
  (тег с дефисом публикуется как pre-release). Подпись release-сборки берётся из секретов keystore, если они заданы в форке.
